Privacy details

When enabled, requests are stored privately for 30 days. Email is used for the publisher's reply. Your device code identifies this installation without sharing raw hardware details.

The form sends only when you choose Send request. A device code in a launcher link reaches the website host before it is removed from the address. Requests need manual approval; no license is issued automatically.
