How setup works

  1. Open the launcher

    When the public launcher is available, open it on the Windows PC you want to use.

  2. Request a device license

    Choose Request license in the launcher. Use its complete device code and a reply email address in this form.

  3. Import your license

    After the publisher approves your request and provides the license file, import it in the launcher. Keep the file for this device.

Lite and Full access comes from a verified license. Choosing a tier in a request does not activate it.

How request data is handled

When enabled, requests contain your email, device code, requested tier and optional name. They are stored privately and expire after 30 days. Sending a request does not issue a license or send an automatic email.

The form sends only when you choose Send request. If a launcher link includes a device code in its query, that code reaches the website host before it is removed from the page address. No passwords, license files or raw hardware details are requested.
